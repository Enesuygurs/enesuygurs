### 👋 About me

I'm a full-stack developer from Türkiye. I like building practical tools end to end, from the UI down to the system layer:

- 🖥️ **Desktop apps** with Electron and C# WinForms
- 🌐 **Web dashboards** with Next.js, React and TypeScript
- 🧩 **Browser extensions** and **Python automation** utilities
- 🔧 **Open source:** I fix bugs in libraries used by millions of developers, including three.js, Ant Design, Leaflet, mobx, Mongoose and htmx
